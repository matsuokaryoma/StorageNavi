# IMAZO置場管理アプリ　説明資料

> 対象読者: 管理者・導入検討担当者  
> 作成日: 2026-05-24

---

## 1. このアプリが解決する課題

造船所の鉄板加工工程と組立工程の間には、加工済みパーツを一時保管する「置場」があります。
現状は口頭・メモ・記憶に頼った管理が行われており、以下の問題が生じています。

| 課題 | 具体的な状況 |
|---|---|
| **どこにあるか分からない** | パーツが広い置場のどこに置いてあるか、探すのに時間がかかる |
| **使ったかどうか分からない** | 搬出済みかを確認する手段がなく、二重作業や取り違えが起きる |
| **誰が・いつ触ったか分からない** | トラブル時の原因追跡に手間がかかる |
| **紙・口頭では引き継ぎできない** | 担当者が変わると情報が途切れる |

**IMAZO置場管理**は、これらをiPhoneだけで解決するアプリです。

## 3. 主な機能

### 🔵 登録（加工担当者が使う）

1. iPhoneのカメラでパーツに印字された文字をかざす
2. **OCR（文字認識）** が自動的に文字を読み取り、パーツ名として設定
3. **GPS位置情報**を自動取得し、今いる場所を「置場の場所」として記録
4. 必要であれば名前・備考を修正して「保存」

カメラをかざすだけで登録が完了するため、紙やキーボード入力は不要です。

---

### 🔵 検索・場所確認（両工程の担当者が使う）

- パーツ名の一部を入力して検索（部分一致）
- カメラでスキャンした結果をそのまま検索クエリにも使えます
- 検索結果からパーツをタップ → **地図で登録場所を確認**
- OCRで読み取ったテキスト全体も検索対象にできる（オプション）

---

### 🔵 使用済みに変更（組立担当者が使う）

- パーツを検索・特定したら「使用済みにする」ボタンをタップ
- 確認ダイアログの後、ステータスと使用日時が自動記録される
- 間違えた場合は「置場に戻す」で保管中に戻せる

---

### 🔵 全パーツ地図表示

- 保管中のすべてのパーツを地図上にピンで一覧表示
- 使用済みパーツも切り替えで表示可能
- ピンをタップすると詳細画面に遷移

---

### 🔵 監査ログ

- 登録・編集・使用済み化・位置情報更新など、すべての操作を自動記録
- 「誰が・いつ・何をしたか」をアプリ内でいつでも確認できる
- ログは追記専用（後から書き換え・削除不可）

---

### 🔵 長期保管パーツの自動通知

- 6か月以上更新されていない「保管中」パーツを自動的に検出
- アプリ起動時に一覧を表示し、使用済みへの一括変更を提案
- チェックを外したパーツは変更せず、後で個別対応も可能

---

### 🔵 CSVエクスポート

- 設定画面から全パーツデータをCSVファイルに書き出せる
- Excelで開ける形式（UTF-8 BOM付き）
- AirDrop・メール・ファイルアプリへの保存など、標準の共有機能で送付可能

---

## 4. 操作の流れ（代表的なシナリオ）

### シナリオA：加工工程 → 置場に搬出するとき

```
iPhoneを起動
  ↓
「登録する」をタップ
  ↓
パーツの印字にカメラをかざす（1〜3秒）
  ↓
パーツ名と現在地が自動入力される
  ↓
内容を確認して「保存」
  ↓
完了（30秒以内）
```

### シナリオB：組立工程 → パーツを探して使うとき

```
「データを探す」をタップ
  ↓
パーツ名の一部を入力 or カメラでスキャン
  ↓
一覧から対象パーツをタップ
  ↓
地図タブで置場の場所を確認
  ↓
現地でパーツを取り出したら「使用済みにする」をタップ
  ↓
完了
```

| 現状の問題 | 期待できる改善 |

## 6. システム構成

```
[iPhone（現場担当者）]
        │
        ├─ カメラ → OCR（文字認識）
        ├─ GPS → 位置情報取得
        └─ ローカルDB（SwiftData）に保存
                  ↑
           端末内完結（フェーズ1）
```

フェーズ1はインターネット接続なし・外部サーバーなしで完全動作します。
データはiPhone本体にのみ保存されます。

**フェーズ2（将来）**: OneDrive（Microsoft Graph API）経由での複数端末同期を予定しています。
社内のMicrosoftアカウントと連携し、端末をまたいだリアルタイムな情報共有が可能になります。

## 7. セキュリティ・データ管理

| 項目 | 対応内容 |
|---|---|
| データ暗号化 | iOSのデータ保護機能を使用。ロック画面時はアクセス不可 |
| iCloudバックアップ | **対象外に設定済み**（社外クラウドへの自動送信なし）|
| 位置情報 | アプリ使用中のみ取得。バックグラウンドでの追跡なし |
| カメラ | 撮影画像は端末ローカルのみに保存 |
| 操作ログ | 追記専用。後から改ざん・削除不可の設計 |
| MDM対応 | CLOMO MDM管理下のiPhoneでの配布を想定済み |
